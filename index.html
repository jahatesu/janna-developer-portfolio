Harvard Resume
Generator

A responsive resume-building application that transforms structured user input into a polished Harvard-style resume with a real-time preview and downloadable output.

  • React
  • JavaScript
  • HTML5
  • CSS3
  • Vite
Inside the project +
The problem
Creating and updating a professionally formatted resume manually can be repetitive, time-consuming, and prone to inconsistent formatting.
The solution
A browser-based resume generator that converts structured user information into a consistent Harvard-style resume while displaying changes through a live preview.
Architecture
React components manage individual resume sections while application state synchronizes user inputs with the rendered document preview.
Key features
Live preview, editable personal information, education, experience, skills and project sections, reusable components, and downloadable resume output.
Engineering focus
Reusable component design, responsive layouts, state synchronization, document formatting, and maintaining consistency between user input and rendered output.

INPUT→MODEL→EXPLANATION

XeeAI:
Explainable AI

An explainable AI platform designed to make machine-learning predictions easier to understand by revealing how individual inputs influence model decisions through C-LIME interpretability and interactive visualizations.

  • Next.js
  • React
  • TypeScript
  • Python
  • FastAPI
  • Gemini AI
  • scikit-learn
Inside the research +
The problem
Machine-learning models can generate useful predictions while providing limited visibility into the factors that influenced a particular result.
The approach
XeeAI combines machine-learning predictions with explainability techniques to help users understand how individual input features contribute to a model's output.
Architecture
React and Next.js power the interactive frontend while Python and FastAPI handle model analysis, explainability processing, and visualization data.
Explainability
C-LIME interpretability is used to communicate the influence of individual inputs on model predictions through understandable and interactive visual representations.
Contribution
Full-stack development, frontend implementation, backend integration, explainability integration, and interactive data visualization.
Recognition
Recognized with the Best Thesis Award.
